# 대기대순환 시뮬레이터 (atmosim) — 설계 문서

날짜: 2026-06-10
상태: 승인됨

## 목적

수업용 대기대순환 시각화 도구. 지구의 공전에 따른 계절 변화, 자전, 월별 대기대순환(무역풍·편서풍·극동풍), 백야·극야를 3D로 표현하고 리모콘 패널로 조절한다.

## 확정 요구사항

- 3D 지구본 (Three.js CDN, 빌드 도구 없음)
- 실사 텍스처 (Blue Marble 계열, 오버레이가 잘 보이도록 채도 약간 낮춤)
- 한 씬에서 줌 인/아웃: 줌아웃 = 공전 궤도 뷰, 줌인 = 지구 뷰
- 자전: 재생/정지/속도 조절
- 공전: 재생/정지/속도 조절 + 날짜 슬라이더(1/1~12/31) + 절기 점프(춘분/하지/추분/동지)
- 바람 화살표 3종: 무역풍(NE/SE), 편서풍, 극동풍 — 흐르는 애니메이션
- 기압대 띠: 적도저압대, 아열대고압대(30°), 한대전선(60°), 극고압
- ITCZ 라인 + 월별 남북 이동 (바람 띠 전체가 함께 이동)
- 위도선(적도·회귀선·극권) + 한글 라벨
- 3세포 순환(해들리·페렐·극) 수직 단면 표시
- 백야/극야 영역 강조 + 라벨
- 카메라 프리셋: 기본 / 북극 위 / 남극 위 / 적도 / 궤도 전체
- 모든 오버레이 개별 ON/OFF 토글
- 리모콘: 화면 하단 고정 패널 + 키보드 단축키
- 배포: GitHub Pages 새 레포 (yhk1m/atmosim)

## 씬 구조

우주 씬 하나로 구성:

- **태양**: 원점 고정. DirectionalLight(또는 PointLight) + 발광 구체. 실제 광원이므로 명암경계선·백야·극야가 물리적으로 자동 표현된다.
- **지구 시스템**: 궤도 위를 공전하는 그룹. 자전축은 우주 기준으로 방향 고정된 23.5° 기울기. 모든 오버레이(화살표·띠·라벨)는 지구의 자식으로 함께 회전.
- **궤도 링**: 원형 점선 + 춘분/하지/추분/동지 위치 마커와 라벨.
- **카메라**: OrbitControls, target은 항상 지구. 줌 레벨에 따라 궤도 요소/지구 요소 라벨이 자동 페이드 인/아웃.
- 크기·거리는 비실제 도식적 축척.

## 천문 계산 (astro.js — 순수 함수)

- 공전각 θ = (경과일 / 365) × 360°
- 태양적위 δ = −23.44° × cos(360° × (N + 10) / 365), N = 1월 1일부터 경과일
- 백야 한계위도 = 90° − δ (북반구 여름 기준; 남반구는 대칭으로 극야)
- ITCZ 위도 ≈ δ × 0.4 (도식적 근사; 7월 약 +9°, 1월 약 −9°)
- 바람 띠 경계 = 기본 위도(0/30/60) + ITCZ 이동량 비례 오프셋

## 오버레이 레이어 (각각 토글)

| 레이어 | 표현 | 색 |
|---|---|---|
| 무역풍 | 0~30°, 적도 쪽 사선 화살표 | 주황빨강 |
| 편서풍 | 30~60°, 동향 화살표 | 파랑 |
| 극동풍 | 60~90°, 서향 화살표 | 보라 |
| 기압대 | 반투명 띠 4종 | 저압=붉은 계열, 고압=푸른 계열 |
| ITCZ | 굵은 노란 점선 링, 월별 이동 | 노랑 |
| 위도선+라벨 | 적도·회귀선·극권 + 한글 라벨(CSS2DRenderer) | 흰색 계열 |
| 3세포 단면 | 지구 옆 반투명 수직 반원판 + 해들리⟲ 페렐⟳ 극⟲ 화살표 애니메이션 | — |
| 백야/극야 | 극지방 글로우 캡(백야=밝은 링, 극야=어두운 링) + 라벨 | — |

화살표는 구면 위 곡선을 따라 흐르는 애니메이션으로 바람 방향을 표현한다.

## 리모콘 (하단 고정 패널)

- 자전: 재생/정지, 속도 슬라이더
- 공전: 재생/정지, 속도 슬라이더
- 날짜: 슬라이더(1/1~12/31) + 절기 점프 버튼 4개
- 표시 토글: 바람/기압대/ITCZ/위도선/3세포/백야표시
- 시점: 기본/북극 위/남극 위/적도/궤도 전체
- 현재 상태 표시줄: 날짜 · 절기 · 태양적위 · ITCZ 위도
- 키보드: Space=자전 토글, ←→=날짜 이동, 1~4=절기 점프

## 아키텍처

```
atmosim/
├── index.html            ES Module + importmap (Three.js CDN)
├── css/style.css
├── js/
│   ├── main.js           초기화 + 렌더 루프
│   ├── state.js          단일 상태 객체 + pub/sub 구독
│   ├── astro.js          천문 계산 (순수 함수)
│   ├── scene/
│   │   ├── sun.js  orbit.js  earth.js
│   │   ├── wind.js  belts.js  cells.js  polar.js
│   └── ui/remote.js      리모콘 (state만 변경)
└── assets/earth.jpg      텍스처 로컬 포함
```

- 데이터 흐름 단방향: 리모콘 → state(pub/sub) → 씬 모듈 구독. 모듈 간 직접 호출 없음.
- state 형태: `{ dayOfYear, rotating, rotationSpeed, revolving, revolutionSpeed, toggles: {...}, cameraPreset }`
- 빌드 없음: index.html 더블클릭 실행 가능, 폴더 그대로 GitHub Pages 배포.

## 오류 처리

- 텍스처 로드 실패 시 단색 구 + 콘솔 경고로 동작 지속.
- WebGL 미지원 브라우저: 안내 메시지 표시.

## 검증

- astro.js: 기준값 수동 검증 (하지 δ≈+23.4°, 동지 δ≈−23.4°, 춘·추분 δ≈0°).
- 시각 요소: 절기별 스크린샷 체크리스트 (하지 북극 백야, 동지 북극 극야, ITCZ 7월 북상 등).

## 구현 단계

1. 씬 골격: 태양+지구+궤도, 자전/공전, 줌 인아웃, 명암
2. astro.js: 날짜→적위, 계절 마커, 날짜 슬라이더
3. 대기대순환: 바람 화살표 3종 + 기압대 + ITCZ 계절 이동
4. 3세포 단면 + 백야/극야 표시 + 카메라 프리셋
5. 리모콘 완성 + 라벨 + 디자인 + GitHub Pages 배포

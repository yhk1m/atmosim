## 1. 프로젝트 개요

지구의 공전(계절 변화), 자전, 대기대순환(무역풍·편서풍·극동풍), 백야·극야를 3D로 표현하는 **수업용 시뮬레이터**.

- **기술**: Three.js 0.160 (CDN importmap), 바닐라 JS ES Modules, 빌드 도구 없음
- **배포**: git push → GitHub Pages 자동 배포 → gcs.bgnl.kr (가비아 DNS)
- **로컬 실행**: `npx -y http-server -p 8080 -c-1`
- **테스트**: `node tests/astro.test.mjs && node tests/state.test.mjs`

## 2. 핵심 아키텍처

```
우주 씬 (태양 = 원점, 실제 광원)
└─ 지구 시스템
   ├─ system  : 공전 위치 (황도면) ← 달 궤도 부착
   ├─ tilted  : 자전축 23.44° 기울기 ← 오버레이(바람·기압대·위도선·3세포·백야캡) 부착
   └─ spin    : 자전 ← 지구 메시 + 열적도 ITCZ(대륙 고정) 부착

데이터 흐름(단방향): 리모콘 → state(pub/sub) → 씬 모듈 update(state, dt)
카메라: OrbitControls가 지구를 추적. 줌아웃=궤도 뷰 / 줌인=지구 뷰 (라벨 자동 페이드)
```

**핵심 규약 — 하지(day 172) 앵커**: 태양적위와 공전각이 모두 `(day−172)` 기준이라
조명 기하(명암경계·백야)와 수치 계산(ITCZ·HUD)이 자동으로 일치한다.

```
태양적위 δ(day) = 23.44° × cos(2π(day−172)/365)     — 하지 +23.44°, 동지 −23.44°
공전각 θ(day)  = π + 2π(day−172)/365                 — 하지에 지구가 (−30, 0, 0)
ITCZ(동서평균) = 0.4 × δ
열적도(경도별) = 해양 2.5° + 4.5°×계절 + Σ 대륙 가우시안 끌림(자기 반구 여름에만)
```

## 3. 개발 과정 타임라인

### 1차 — 설계와 기본 구현 (2026-06-10)
- 브레인스토밍 → 설계 문서 → 11개 태스크 구현 계획 (`docs/superpowers/`)
- 서브에이전트 방식으로 태스크별 구현 + 2단계 리뷰(스펙/품질)
- 씬 골격(태양·궤도·지구), astro.js(TDD), state.js(TDD), 바람 화살표 3종,
  기압대, 위도선+한글 라벨, 3세포 단면, 백야/극야, 리모콘, GitHub Pages 배포

### 2차 — 리모콘과 시각 개선
- 리모콘 위치 전환(하단/좌/우 — 좌우는 세로형) + 숨기기/표시(localStorage 기억)
- 바람 토글 3분리(무역풍/편서풍/극동풍), 바람 라벨 반대편(−X) 이동
- 바람 화살표: 이동 애니메이션 → **긴 사선 점선 + 아우디식 순차 점등**으로 교체
- 3세포: 극세포를 85°에서 하강시켜 극점 수렴 제거

### 3차 — 콘텐츠 정밀화 (ultracode 멀티에이전트 검증)
- 3세포 2배 확대 + 흰 단면판이 **대류권계면 모양**(적도 17km : 극 8km 비율)을 따름
- 낮 면 55% 밝게(재질 감쇠 제거 + 광량 2.9)
- 일괄 토글(바람 전체/전체, indeterminate 표시), 세로 모드 체크란 2열
- 기압대 명칭 7개 라벨(적도 저압대/아열대 고압대/고위도 저압대/극고압대)
- **ITCZ → 열적도 물결선**: 대륙(아프리카 22E·남아시아 90E·호주 130E·남미 −60E) 위
  진폭 크고 해양 작음, 대륙은 자기 반구 여름에만 끌어당김, spin 그룹 부착(대륙 고정)
- 🐛 **r160 CSS2DRenderer가 부모 그룹 visible을 무시하는 버그 발견** (8개 에이전트
  병렬 리뷰 + CDN 소스 검증) → 모든 한글 라벨을 자체 visible 플래그로 제어하도록 수정

### 4차 — 천체와 편의 기능
- 위도선 4분리 토글(적도/회귀선/30·60도선(신규, 점선)/극권)
- 전체화면 버튼, 절기 날짜 병기(춘분 3/20~21 등), 카피라이트
- **달 추가**: 황도면 궤도, 항성월 27.32일, 위상은 광원으로 자동 표현
- 🐛 공전 방향 수정: 자전과 같은 반시계(북쪽 기준)로 통일 — 실제 지구와 일치

### 5차 — 마무리 다듬기
- 위선 전체 일괄 토글, 달 토글, 태양 라벨, Copyright 표기
- 위도 라벨 N/S·도수 병기(30°N, 북회귀선(23.5°N) 등)
- 달 거리 2배(4R), 우상단 **? 축척 안내 패널**
- 🐛 "배포했는데 안 보여요" 반복 → 원인은 GitHub Pages 10분 캐시.
  헤드리스 Edge로 코드 정상 동작을 스크린샷 검증한 뒤,
  **서비스 워커(sw.js)** 추가로 근본 해결 — 이후 일반 새로고침만으로 항상 최신

### 6차 — 도메인 연결 (2026-06-11)
- GitHub Pages 커스텀 도메인 `gcs.bgnl.kr` 설정 (CNAME 파일 자동 커밋)
- 가비아 DNS: `CNAME gcs → yhk1m.github.io.` 추가
- HTTPS 인증서(Let's Encrypt) 자동 발급 → 발급 즉시 HTTPS 강제 적용
- "주의 요함" 표시는 인증서 발급 전 HTTP 접속 시의 정상 표시

## 6. 사용법 요약

- **리모콘**: 자전/공전 재생·속도, 날짜 슬라이더, 절기 점프, 표시 토글(개별+일괄),
  시점 프리셋(기본/북극/남극/적도/궤도 전체), 위치 이동(◀▼▶)/숨기기, 전체화면
- **키보드**: `Space` 자전 토글 · `←→` 날짜 ±1일 · `1~4` 절기 점프
- **수업 포인트**: 북극 위 시점+하지 → 백야 관찰 / 기압대(동서평균) vs 열적도(국지
  몬순)가 여름 아시아에서 ~9° 어긋나는 것은 의도된 교육 포인트
